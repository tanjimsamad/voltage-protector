# Microcontroller-Based Voltage Protector

## Project Overview
This project focuses on designing and simulating a microcontroller-based voltage protector that detects abnormal voltage and overcurrent conditions and disconnects the protected load when a fault is detected.

## Project Features
- Voltage monitoring and fault detection
- Overcurrent fault detection
- Load disconnection during fault conditions
- Computer communication and configurable settings, as implemented
- Simulation-based testing

## Repository Structure
- `src/` — Source code
- `schematics/` — Circuit schematics and block diagram
- `test_evidence/` — Simulation screenshots and test results
- `project_files/` — Simulation project files
- `design_document.pdf` — Project report

## How to Run
1. Open the project using the simulation software used for development.
2. Load the simulation project files.
3. Follow the project-specific setup instructions.
4. Run the simulation and observe the protection response.

## Testing and Limitations
Refer to the project report and test evidence for the actual results, implemented functionality, and limitations.

This project was evaluated through simulation. Hardware performance under real mains-voltage conditions has not been established by simulation alone.
